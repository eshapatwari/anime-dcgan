# Anime Image Generation using DCGAN

## Overview
An ongoing deep learning project exploring anime image generation using a Deep Convolutional Generative Adversarial Network (DCGAN).

## Tech Stack
- Python
- PyTorch
- Torchvision
- Jupyter Notebook

## Current Progress
The project is a work in progress. The notebook contains the current implementation and experiments.

## Objectives
- Implement a generator and discriminator.
- Train the GAN on anime images.
- Generate synthetic anime-style images.
- Evaluate and improve the quality of generated samples.

## How to Run
1. Clone this repository.
2. Install the required dependencies.
3. Open `GAN.ipynb` in Jupyter Notebook or VS Code.
4. Select a compatible Python kernel and run the notebook cells.
